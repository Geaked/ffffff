# Сайт-розыгрыш со скримером (Dota 2 буст)

Одностраничный статический сайт-прикол в стиле буст-сервиса по Dota 2.

## Как работает

1. Жертва открывает `index.html` и видит лендинг DOTA BOOST PRO: ранги, отзывы, «бесплатный буст до Immortal», таймер обратного отсчёта.
2. Жмёт пульсирующую кнопку **⚡ ЗАБРАТЬ БУСТ ⚡** — поверх страницы открывается панель «Подключение к серверу буста» с зелёной консолью и прогресс-баром.
3. По достижении 100% срабатывает скример: вспышка, тряска, страшное лицо во весь экран и громкий звук, сгенерированный через Web Audio API (без внешних файлов).

Один файл, один клик. Никаких других страниц.

## Как открыть

Двойной клик по `index.html` — откроется в браузере. Для подгрузки шрифтов с Google Fonts нужен интернет; без него страница тоже работает, но шрифт будет резервный.

## ⚠️ Предупреждение

Скример воспроизводит резкий громкий звук и пугающее изображение с тряской и вспышкой. Не показывать людям с эпилепсией, проблемами с сердцем или повышенной чувствительностью к внезапным эффектам. Убавьте громкость на устройстве жертвы, если хотите смягчить эффект.
