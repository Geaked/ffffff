# Сайт-розыгрыш со скримером

Простой статический сайт-прикол на двух страницах:

- `index.html` — заманчивая страница «Вы выиграли приз!» с большой яркой кнопкой и таймером обратного отсчёта.
- `prize.html` — фейковая полоса загрузки приза, в конце которой срабатывает скример: страшное лицо на весь экран, тряска, вспышка и громкий звук, сгенерированный через Web Audio API (без внешних файлов).

## Как открыть

Просто откройте `index.html` в браузере (двойной клик или через локальный сервер, например `python3 -m http.server`).

## ⚠️ Предупреждение

На странице `prize.html` воспроизводится громкий резкий звук и появляется пугающее изображение. Не показывайте людям с эпилепсией, проблемами с сердцем или повышенной чувствительностью к внезапным эффектам. Перед показом другу убедитесь, что у него на устройстве не выкручена громкость на максимум.
